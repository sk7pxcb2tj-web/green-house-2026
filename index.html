คู่มือการ Deployment บน GitHub Pages & Firebase Hosting

วิธีที่ 1: Deploy ผ่าน GitHub Pages (ฟรี)
  1. สร้าง Repository บน GitHub ชื่อ green-house-2026
  2. อัปโหลดไฟล์ index.html ขึ้นไปยัง branch main
  3. ไปที่ **Settings** → **Pages** ในแถบเมนูด้านข้าง
  4. ในส่วน Source ให้เลือก **Deploy from a branch** แล้วเลือก branch **main** (/root)
  5. กด **Save** รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น https://yourusername.github.io/green-house-2026/
วิธีที่ 2: Deploy ผ่าน Firebase Hosting
  1. ติดตั้ง Firebase CLI บนคอมพิวเตอร์: npm install -g firebase-tools
  2. เข้าสู่ระบบผ่าน Terminal: firebase login
  3. สั่งเริ่มต้นโปรเจกต์: firebase init hosting
  4. ตั้งค่า public directory เป็นโฟลเดอร์ที่เก็บ index.html
  5. เผยแพร่ออนไลน์: firebase deploy
